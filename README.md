#  ClinicSoft

**ClinicSoft** — это десктопное приложение для автоматизации деятельности медицинских клиник среднего масштаба. Система объединяет врачей, регистраторов, пациентов и администраторов в единое цифровое пространство, минимизируя бумажный документооборот и повышая точность учета.

Приложение разработано с акцентом на простоту внедрения, безопасность персональных данных и удобство пользовательского интерфейса.


## ✨ Основные возможности

*    **Управление расписанием:** Запись пациентов с автоматической проверкой доступности слотов и предотвращением конфликтов.
*    **Электронная медицинская карта:** Хранение анамнеза, аллергий, хронических заболеваний и истории посещений.
*   👩‍️ **Проведение приёма:** Фиксация жалоб, выбор диагноза из справочника, назначение анализов и лечения.
*   🧪 **Лабораторный модуль:** Формирование заказов на анализы, ввод результатов лаборантом и их привязка к визиту.
*    **Документооборот:** Генерация официальных документов (справок, заключений) в формате PDF прямо из приложения.
*   🔐 **Безопасность:** Хэширование паролей (BCrypt), строгая ролевая модель доступа и защита персональных данных.

## 👥 Роли пользователей

| Роль | Описание |
| :--- | :--- |
| **Администратор** | Управление пользователями, справочниками (специальности, диагнозы) и справочными данными клиники. |
| **Врач** | Ведение приёма, назначение лечения, просмотр истории болезни, формирование заключений. |
| **Регистратор** | Запись пациентов на приём, управление расписанием врачей, создание первичных записей. |
| **Пациент** | Самостоятельная запись на приём, просмотр своих анализов и назначений. |
| **Лаборант** | Ввод результатов лабораторных исследований. |

##  Технологический стек

Проект построен на современной экосистеме Microsoft .NET:

*   **Язык:** C# 12
*   **Платформа:** .NET 8.0
*   **UI Фреймворк:** WPF (Windows Presentation Foundation)
*   **База данных:** PostgreSQL 15
*   **ORM:** Entity Framework Core + Npgsql
*   **Безопасность:** BCrypt.Net
*   **Генерация PDF:** QuestPDF

##  Системные требования

Для работы приложения необходима ОС Windows 10/11.

**Минимальные характеристики:**
*   Процессор: x64
*   ОЗУ: 4 ГБ
*   Место на диске: 500 МБ
*   Сеть: Доступ к серверу с установленной СУБД PostgreSQL

## 🚀 Установка и запуск

Приложение распространяется в виде самодостаточной сборки (Self-contained), поэтому установка **.NET Runtime** на клиентский компьютер не требуется.

1.  Скачайте архив с последней версией из раздела **Releases**.
2.  Распакуйте архив в любую удобную папку (например, `C:\ClinicSoft`).
3.  Убедитесь, что у вас есть доступ к серверу PostgreSQL с настроенной базой данных `ClinicSoftDB`.
4.  Проверьте строку подключения в конфигурации приложения (если необходимо).
5.  Запустите файл `ClinicSoft.exe`.

> **Примечание:** Для первого запуска необходимо иметь настроенный сервер PostgreSQL и примененные миграции EF Core для создания схемы БД.

## 📖 Архитектура

Приложение реализовано по классической двухзвенной архитектуре **«Толстый клиент — Сервер БД»**.

*   **Клиент:** WPF-приложение с MVVM-подобной логикой (Code-behind), отвечающее за отображение и взаимодействие с пользователем.
*   **Сервер:** Централизованная СУБД PostgreSQL, обеспечивающая надежность хранения, транзакционность и многопользовательский доступ.
*   **Связь:** Прямое подключение через провайдер `Npgsql` без промежуточных веб-слоев.
